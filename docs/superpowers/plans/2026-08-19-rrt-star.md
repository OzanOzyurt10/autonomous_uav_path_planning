**Amaç:** Mevcut düz RRT planlayıcısını RRT*'a çevirmek — en ucuz ebeveyn seçimi ve yeniden bağlama ekleyerek bütçe boyunca kısalan bir rota üretmek.

**Spec:** `docs/superpowers/specs/2026-08-19-rrt-star-design.md`

## Genel Kısıtlar

- Kod ve docstring **ASCII** — Türkçe karakter kullanılmaz.
- Docstring'ler kısa: 3-5 satır, yalnızca koddan anlaşılmayan gerekçe.
- `raise ValueError(...)`, `return ValueError(...)` değil.
- Mantıksal koşullarda `and` / `or`, `&` / `|` değil.
- Modül seviyesindeki tanımlar arasında iki boş satır; `if` gövdesi alt satırda.
- Yarıçap formülü: `r_n = min(gamma * (log n / n)^(1/3), cap)`, `n <= 1` iken `cap`.
- Varsayılanlar: `radius_gamma = 60.0`, `radius_cap = 30.0`.
- Karşılaştırmalar `<` ile yapılır (`<=` değil) — döngü oluşmasını bu engelliyor.
- Test dosyası mevcut sabitleri kullanır: `BOUNDS`, `RHO = 3.0`, `STEP = 0.5`, `FREE_ENV`, `WALL_ENV`, `START`, `GOAL`, `assert_pose_close`, `_node`.

```python
class TestNeighbourRadius:
    def test_small_tree_uses_cap(self):
        assert _neighbour_radius(0, 60.0, 30.0) == 30.0

        small = _neighbour_radius(500, 30.0, 1000.0)
        large = _neighbour_radius(500, 60.0, 1000.0)
```

Tam imza:
```python
def _neighbour_radius(n: int, gamma: float, cap: float) -> float:
```

**Sözleşme:** `min(gamma * (log n / n) ** (1/3), cap)` döndürür. `n <= 1` ise
doğrudan `cap` döndürür — `log 1 = 0` olduğu için formül sıfır verir ve hiçbir
komşu bulunamazdı.

Guard clause ile başla:
```python
    if n <= 1:
        return cap
    return min(...)
```

`math.log(n)` doğal logaritma. Küp kök `** (1 / 3)` ile yazılır.

**Öncelik tuzağı:** `gamma * math.log(n) / n ** (1 / 3)` yanlış — `**` çarpma ve
bölmeden önce bağlanır, yani `n`'in küp kökü alınır, oran değil. Parantez şart:
`gamma * (math.log(n) / n) ** (1 / 3)`.

Docstring: üs `1/3` çünkü konfigürasyon uzayı SE(2) üç boyutlu; formül Öklid
uzayı için ispatlanmış, Dubins'e uygulanması yaklaşıklık.

Tam imza:
```python
def _neighbours(nodes: list[Node], pose: Pose, radius: float) -> list[int]:
```

**Sözleşme:** Öklid mesafesi `radius`'tan büyük **olmayan** düğümlerin
indekslerini artan sırada döndürür. Dubins çözmez.

Öklid mesafesi: `math.hypot(node.pose[0] - pose[0], node.pose[1] - pose[1])`.
Karşılaştırma `<=` ile — sınırdaki düğüm dahil (`test_zero_radius_gives_only_coincident`
sıfır yarıçapta kendi konumundaki düğümü bekliyor).

Bir liste kavraması (list comprehension) ile tek satırda yazılır:
```python
    return [i for i in range(len(nodes)) if <mesafe kosulu>]
```
Bu, boş liste açıp `for` döngüsünde `append` etmenin kısa yazımı; ikisi de olur.

Docstring: eleme neden **kayıpsız** — bir Dubins yolu düz çizgiden kısa olamaz,
dolayısıyla Öklid mesafesi yarıçapı aşan bir düğümün Dubins mesafesi de aşar.
Ayrıca fonksiyon yön bilmiyor, iki işleme de hizmet ediyor.

Tam imza:
```python
def _choose_parent(env: Environment, nodes: list[Node], pose: Pose,
                   candidates: list[int], rho: float, step: float,
                   fallback: tuple[int, DubinsPath]) -> tuple[int, DubinsPath]:
```

**Sözleşme:** Adaylar arasından `pose`'a en ucuza ulaştıranı seçer ve
`(indeks, kenar)` döndürür. Hiçbiri `fallback`'ten iyi değilse `fallback`
aynen döner.

Maliyet formülü — **yön kritik**:
```
nodes[j].cost + d(nodes[j].pose -> pose)
```
Yani kenar **adaydan yeni poza** kurulur. Tersi (`pose -> nodes[j].pose`)
farklı bir sayıdır ve sessizce yanlış ağaç kurar.

İskelet:
```python
    best_index, best_edge = fallback
    best_cost = nodes[best_index].cost + best_edge.length
    for j in candidates:
        edge = _try_connect(env, nodes[j].pose, pose, rho, step)
        if edge is None:
            continue
        cost = nodes[j].cost + edge.length
        if cost < best_cost:
            best_index, best_edge, best_cost = j, edge, cost
    return best_index, best_edge
```

Üç not:

`_try_connect` çarpışma kontrolünü de yapıyor; `None` dönen aday elenir
(`test_blocked_candidate_is_skipped`).

Karşılaştırma `<` — eşitlikte `fallback` kalır, gereksiz kenar değişimi olmaz.

`fallback` zaten hesaplanmış kenarı taşır (`_nearest`'in bulduğu). Aday
listesinde aynı indeks tekrar çıkarsa aynı sonucu verir, zararı yok.

Docstring: yönün neden `aday -> yeni poz` olduğu.

```python
            if node.parent is None:

            expected = tree[node.parent].cost + node.path_from_parent.length
            assert math.isclose(node.cost, expected, abs_tol=1e-9)
```

Döngü içinde, `edge is None` kontrolünden **sonra**:

Eski `if best is not None: continue` satırı **kalkıyor** — artık her hedef
bağlantısı listeye giriyor.

Döngüden sonra:
```python
    if not goal_links:
        return RRTResult(False, [], math.inf, max_iterations, nodes)

    index, goal_edge = min(goal_links,
                           key=lambda link: nodes[link[0]].cost + link[1].length)

    cost = nodes[index].cost + goal_edge.length
```

Üç not:

`_neighbours` **eklemeden önce** çağrılıyor; indeksler o anki listeye göre
geçerli ve yeni düğüm kendi komşusu olamaz.

`_choose_parent`'a `fallback` olarak `(i, edge)` veriliyor — `_nearest`'in
bulduğu ve zaten çarpışma kontrolünden geçmiş çift. Dönüş değeri aynı iki
değişkene atanıyor, sonraki satır onları kullanıyor.

`min(..., key=lambda link: ...)` liste elemanları demet olduğu için

```python
        a = (0.0, 0.0, 0.0)

        bc = shortest_path(b, c, RHO)
        cd = shortest_path(c, d, RHO)

            Node(b, 0, ab.length, ab),
            Node(c, 1, ab.length + bc.length, bc),
            Node(d, 2, ab.length + bc.length + cd.length, cd),
        ]

    def test_no_change_when_costs_already_correct(self):

        before = [n.cost for n in nodes]
        _propagate_cost(nodes, 0)
        assert [n.cost for n in nodes] == before

    def test_updates_whole_subtree(self):
        nodes = self._chain()
        nodes[1] = dataclasses.replace(nodes[1], cost=100.0)
        _propagate_cost(nodes, 1)
        assert math.isclose(nodes[2].cost,
                            100.0 + nodes[2].path_from_parent.length)

    def test_does_not_touch_siblings(self):
```

- [x] **Adım 3: `_propagate_cost`'u yaz — OZAN**

Tam imza:
```python
def _propagate_cost(nodes: list[Node], index: int) -> None:
```

**Sözleşme:** `nodes[index]`'in altındaki tüm alt ağacın maliyetini günceller.
Listeyi **yerinde** değiştirir, bir şey döndürmez.

`Node` frozen olduğu için maliyeti değiştiremezsin; düğümün yerine yenisini
koyarsın:
```python
    nodes[c] = dataclasses.replace(nodes[c], cost=<yeni maliyet>)
```
`dataclasses.replace` mevcut nesnenin kopyasını çıkarır, yalnızca verdiğin
alanları değiştirir. Diğer alanlar (pose, parent, path_from_parent) aynen kalır.

İskelet — kuyrukla genişlik öncelikli gezinti:
```python
    queue = collections.deque([index])
    while queue:
        i = queue.popleft()
        for c in range(len(nodes)):
            if nodes[c].parent != i:
                continue
            nodes[c] = dataclasses.replace(
                nodes[c], cost=nodes[i].cost + nodes[c].path_from_parent.length)
            queue.append(c)
```

`deque` iki uçlu kuyruk; `popleft()` baştan alır, `append()` sona ekler.
Düz liste ile de olur ama `pop(0)` her seferinde tüm listeyi kaydırır.

**Kenarın geometrisi değişmiyor** — ebeveynin pozu aynı kaldı, sadece ona
kadarki toplam maliyet değişti. Yeniden Dubins çözme.

Dosyanın başına `import collections` ve `dataclasses`'tan `replace` importu
gerekiyor. Mevcut satır `from dataclasses import dataclass`; `dataclass, replace`
yapabilirsin veya `import dataclasses` deyip `dataclasses.replace` yazarsın —
testler ikincisini kullanıyor, ikisi de çalışır.

Docstring: frozen olduğu için `replace` kullanıldığı, ve geometrinin
değişmediği.

- [x] **Adım 3: `_rewire`'ı yaz — OZAN**

Tam imza:
```python
def _rewire(env: Environment, nodes: list[Node], new_index: int,
            candidates: list[int], rho: float, step: float) -> None:
```

**Sözleşme:** Her aday için "yeni düğüm üzerinden gelmek daha ucuz mu" diye
sorar; ucuzsa adayın ebeveynini yeni düğüm yapar ve alt ağacına maliyeti yayar.
Listeyi yerinde değiştirir, bir şey döndürmez.

Maliyet formülü — **`_choose_parent`'ın tersi yön**:
```
nodes[new_index].cost + d(nodes[new_index].pose -> nodes[j].pose)
```
Kenar **yeni düğümden adaya** kurulur. `_choose_parent`'ta adaydan yeni poza
kuruyorduk; bu iki sayı farklıdır ve karıştırılırsa kod çalışır ama sonuç
optimal olmaz.

İskelet:
```python
    for j in candidates:
        if j == new_index:
            continue
        edge = _try_connect(env, nodes[new_index].pose, nodes[j].pose, rho, step)
        if edge is None:
            continue
        cost = nodes[new_index].cost + edge.length
        if cost >= nodes[j].cost:
            continue
        nodes[j] = dataclasses.replace(nodes[j], parent=new_index, cost=cost,
                                       path_from_parent=edge)
        _propagate_cost(nodes, j)
```

Üç not:

`j == new_index` kontrolü şart — düğüm kendi ebeveyni olamaz.

Karşılaştırma `cost >= nodes[j].cost` ise atla, yani iyileştirme **kesin**
olmalı. `<=` ile atlarsan eşitlikte de bağlarsın; sıfır uzunluklu kenarlarda
bu döngü kurabilir.

`_propagate_cost` her yeniden bağlamadan **hemen sonra** çağrılıyor, döngü
bittikten sonra değil. Sonraki adayın karşılaştırması güncel maliyetleri
görmeli.

Docstring: yönün `_choose_parent`'ın tersi olduğu, ve ayrı bir döngü kontrolü
neden gerekmediği (bir ata için `yeni.cost + d(yeni->ata) > ata.cost` her zaman
doğru, çünkü kenar uzunlukları pozitif).

```python
    def test_curvature_never_exceeds_limit(self):
        for edge in self._star().edges:
            points = edge.sample(0.05)

                ds = math.hypot(b[0] - a[0], b[1] - a[1])
```
