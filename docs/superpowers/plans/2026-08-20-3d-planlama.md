1. **Modül docstring'i.** Ne olduğu (3B ortam: silindir engeller, irtifa

   ```
   Point3  -> uc float
   Pose3   -> dort float
   Bounds3 -> alti float
   ```
4. **`Cylinder`** — `@dataclass(frozen=True)`, beş alan sırayla: `x`, `y`,

   `z_max <= z_min` → `raise ValueError(...)`, mesaja gelen değeri koy.
   `environment.py`'deki `Obstacle.__post_init__` aynı kalıpta.
6. **`contains`** metodu:
   ```python
   def contains(self, point: Point3 | Pose3, clearance: float = 0.0) -> bool:
   ```
   İki koşulun **ikisi birden** sağlanıyorsa `True`:
   - yatay mesafe `<= self.radius + clearance` —
     `math.hypot(point[0] - self.x, point[1] - self.y)`
   - `self.z_min - clearance <= point[2] <= self.z_max + clearance`

   Python'da zincirleme karşılaştırma yazabilirsin: `a <= b <= c` geçerli ve
   ikisini birden kontrol eder.

   İkisini `and` ile bağla, `&` ile değil.

**Tuzak:** `point[2]` z; dört elemanlı poz gelirse `point[3]` yaw olur ve
hiç bakmıyorsun — bu yüzden hem nokta hem poz kabul ediliyor.

Docstring: sonlu yüksekliğin ne demek olduğu (üstünden uçulabilir) ve emniyet
payının dikeyde de uygulandığı.

- [x] **Adım 3: `Environment3D` iskeletini yaz — OZAN**

`Cylinder`'ın altına, `@dataclass(frozen=True)`, üç alan sırayla:

```
bounds     -> Bounds3
obstacles  -> tuple[Cylinder, ...]
clearance  -> float
```

**`is_inside_bounds`:**

```python
    def is_inside_bounds(self, point: Point3 | Pose3) -> bool:
```

`bounds` altı elemanlı; demet açmayla altı değişkene ayır:
`x_min, y_min, z_min, x_max, y_max, z_max = self.bounds`. Sıra bu — z'ler
ortada değil, ilk üç minimum, son üç maksimum.

Sonra üç zincirleme karşılaştırmayı `and` ile bağla:
`x_min <= px <= x_max` gibi, üç eksen için.

**`is_free`:**

```python
    def is_free(self, point: Point3 | Pose3) -> bool:
```

`environment.py`'deki `is_free` ile aynı yapı — guard clause:

1. Sınır dışındaysa hemen `False` döndür
2. Her engel için: `obstacle.contains(point, self.clearance)` doğruysa
   `False` döndür
3. Döngü bitmişse `True`

`any()` ile tek satırda da yazılabilir; 2B'de nasıl yazdıysan aynısı.

**Tuzak:** `clearance` argümanını `contains`'e vermeyi unutma — vermezsen
varsayılan `0.0` kullanılır ve emniyet payı hiç işlemez.

```python
    def suggested_step(self) -> float:
```

**Engel yoksa:** haritanın en kısa kenarının onda biri. Üç kenar var artık:
`x_max - x_min`, `y_max - y_min`, `z_max - z_min`. `min()` üç argüman alabilir.

**Engel varsa:** her silindir için şişirilmiş en küçük yarı-boyutu hesapla:

```
min(radius + clearance, (z_max - z_min) / 2 + clearance)
```

Bunların **en küçüğünü** bul, **yarısını** döndür.

Üç yol var, hangisini istersen: `for` döngüsüyle en küçüğü takip et,
`min()`'e bir liste kavraması ver, ya da `min(..., key=...)`. `_nearest`'te
döngüyle yazmıştın, burada liste kavraması daha kısa:

```python
    yarim_boyutlar = [<her engel icin ifade> for obstacle in self.obstacles]
    return min(yarim_boyutlar) / 2
```

**Neden yükseklik de sayılıyor:** alçak ve geniş bir silindirde yalnızca
yarıçapa bakarsan adım büyük çıkar ve yol engeli dikey olarak atlar —
örnekleme noktaları altında ve üstünde düşer, hiçbiri içine denk gelmez.

Docstring: bu bir sezgisel kural, ayrıklaştırma hatasını tamamen kapatmıyor;
emniyet payı onu yutuyor.

    for i, ad in enumerate(("x", "y", "z")):

            f"{ad}: {actual} vs {expected}"

    def test_costs_are_consistent_with_edges(self, seed):
        tree = _short_result(seed, 120).tree
        for node in tree:
            if node.parent is None:
                continue
            expected = tree[node.parent].cost + node.path_from_parent.length
            assert math.isclose(node.cost, expected, abs_tol=1e-9)

            j = i
            while tree[j].parent is not None:
                j = tree[j].parent
                steps += 1
                assert steps <= len(tree)
            assert j == 0
